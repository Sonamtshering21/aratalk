# Fonts for link-preview images

Used by `app/post/[id]/opengraph-image.tsx`. Static TTF files from Google Fonts, licensed under the SIL Open Font License 1.1 (license texts alongside):

- `Nunito-ExtraBold.ttf`, `Nunito-SemiBold.ttf`: Nunito, the site's font (`OFL-Nunito.txt`)
- `NotoSerifTibetan-Bold.ttf`: Noto Serif Tibetan, so Dzongkha titles render (`OFL-NotoSerifTibetan.txt`)
